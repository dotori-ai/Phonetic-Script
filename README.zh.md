# Phonetic Script

**用一种文字，记录世界的语音。**

Phonetic Script 是一套以韩文字母（谚文）为基础的书写系统，按照实际发音记录任何语言。谚文里已有的音
照常书写；没有的音，例如 f、v、th、西班牙语的颤音，以及汉语的声调，就在熟悉的字母上加一个小记号。

**▶ 中文页面：<https://dotori-ai.github.io/Phonetic-Script/zh/>**

新字母由项目专用字体显示。GitHub 页面没有这个字体，所以下面用 `[声母+韵母+韵尾]` 的结构来表示每个
新字母。请打开上面的页面查看实际字形。

## 声调写在字上

汉语的 ma 因声调不同而有四种意思。标准韩文都写成“마”，而 Phonetic Script 把声调写在每个音节上方的
固定位置，就像拼音的声调符号一样。

| 汉字 | 拼音 | Phonetic Script 结构 | 标准韩文 | 声调 |
|---|---|---|---|---|
| 妈 | mā | `[ㅁ+ㅏˉ]` | 마 | 第一声 · 高平 |
| 麻 | má | `[ㅁ+ㅏˊ]` | 마 | 第二声 · 上升 |
| 马 | mǎ | `[ㅁ+ㅏˇ]` | 마 | 第三声 · 降升 |
| 骂 | mà | `[ㅁ+ㅏˋ]` | 마 | 第四声 · 下降 |

## 例词

每个音节由声母、韵母、韵尾和声调组成。结构一栏用方括号写出每个音节的组成部分。

| 汉字 | 拼音 | Phonetic Script 结构 | IPA |
|---|---|---|---|
| 你好 | nǐ hǎo | `[ㄴ+ㅣˇ][ㅎ+ㅏˇ]오` | ni hao |
| 中国 | zhōng guó | `[ㅈ+ㅜˉ+ㅇ][ㄱ+ㅝˊ]` | ʈʂʊŋ kwo |
| 汉字 | hàn zì | `[ㅎ+ㅏˋ+ㄴ][ㅈ+ㅣˋ]` | xan tsɨ |
| 学生 | xué shēng | `[ㅈ'+ㅠˊ]에[ㅅ-+ㅓˉ+ㅇ]` | ɕɥɛ ʂəŋ |

`ㅈ'`（x 等舌面音）和 `ㅅ-`（sh 等卷舌音）这样的记号，用来区分标准韩文无法区分的汉语声母。

中文支持目前仍处于早期阶段：轻声和变调尚未完全处理，暂时没有语音示例。

## 字母的结构

| 记号位置 | 作用 | 例子 |
|---|---|---|
| 辅音上方 / 右上方 | 韩文没有的辅音 | `ㅍ'` = f · `ㅂ~` = v · `ㅌㅎ` = th · `ㅈ'` = x · `ㅅ-` = sh |
| 元音左侧 | 元音音质 | `·ㅓ` = /ə/ · `·ㅗ` = /ɔ/ |
| 元音右侧 | 长短 | `ㅏː` = 长音 /aː/ |
| 音节上方 | 声调、重音 | 声调 ˉ ˊ ˇ ˋ · 重音 ˈ ˌ |

规则很简单：**一个基本字母 + 一个记号 = 一个新字母。**每个字母都记录六项信息：声母、韵母、韵尾、
声调、重音和音高重音，人看到的字形和计算机读取的信息始终一致。
