# Phonetic Script

**用一种文字，记录世界的语音：每一种方言，每一处细微差别。**

Phonetic Script 是一套为所有语言的声音设计的书写系统。它不按照字典上“应该”的读音来写，而是
记录说话人实际说出的声音：粤语的六个声调、闽南语的变调、乡村里从未被写下的读音。每一种方言、
口音和细微差别都能写下来。

**▶ 中文页面：<https://dotori-ai.github.io/Phonetic-Script/zh/>**

## 为什么：发音比词语承载更多

在训练 AI 语言模型的过程中，我们发现人与人之间的差异更多体现在*怎么发音*，而不是*用哪些词*。
两个人可以逐字说出同一句话，听起来却来自完全不同的地方。只读拼写的 AI 会错过这些差异。要让 AI
听懂方言、口音和语气的细微差别，AI 必须理解声音，也需要一种能把声音写下来的文字。

## 许多说话方式没有属于自己的文字

- **中国。** 粤语、闽南语、吴语、客家话通常用与普通话相同的汉字书写。汉字记录的是意义而不是
  读音，所以声调和许多没有标准汉字的日常词语无法写下来。土家语、仡佬语等少数民族语言甚至没有
  传统文字。
- **印度。** 数千种母语中，像贡德语、比尔语、库鲁克语这样各有数百万使用者的语言，大多只靠口耳
  相传；书写时借用其他语言的文字，失去了自己独有的声音。

没有文字，记录、教育和远距离交流都很困难。Phonetic Script 为这些说话方式提供书写形式。

本页的所有例子都用 IPA（国际音标）表示。

## 声调：同一个音节，四种意思

| 汉字 | 拼音 | IPA | 声调 |
|---|---|---|---|
| 妈 | mā | ma˥ | 第一声 · 高平 |
| 麻 | má | ma˧˥ | 第二声 · 上升 |
| 马 | mǎ | ma˨˩˦ | 第三声 · 降升 |
| 骂 | mà | ma˥˩ | 第四声 · 下降 |

## 例词

| 汉字 | 拼音 | IPA |
|---|---|---|
| 你好 | nǐ hǎo | ni˨˩˦ xau̯˨˩˦ |
| 中国 | zhōng guó | ʈʂʊŋ˥ kuo˧˥ |
| 汉字 | hàn zì | xan˥˩ tsɨ˥˩ |
| 学生 | xué shēng | ɕɥɛ˧˥ ʂəŋ˥ |
| 谢谢 | xièxie | ɕjɛ˥˩ ɕjɛ |

同样的方法也可以记录粤语的六个声调、闽南语的变调，以及没有文字的语言。中文支持目前仍处于早期阶段。
