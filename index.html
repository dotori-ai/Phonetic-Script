Write how the world sounds.

Phonetic Script is a single writing system, built on Hangul, that records how any language is actually pronounced. Sounds Hangul already has are written as they are. For the ones it doesn't (f, v, th, the Spanish trilled rr, Mandarin tones), one small mark is added to a familiar letter.
