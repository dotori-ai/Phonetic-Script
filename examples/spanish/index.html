EK text is a deterministic G2P rendering of each word under the block registry the font was built from. It is baked in at build time: when spellings change in the lexicon editor (or the font is rebuilt) the page is regenerated — the timing is kept, only the text and glyphs change. Words marked ✎ were reviewed by ear: a listener's EK replaces the rendering from the transcription (or rules), which stays in the tooltip — EK is meant to write what is heard, and a phonetic transcription is only a lossy way to get there.
