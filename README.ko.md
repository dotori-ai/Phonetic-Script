# Phonetic Script

**세상의 모든 말소리를 한글로.**

Phonetic Script는 어떤 언어든 실제로 소리 나는 대로 적는 하나의 글자 체계입니다. 한국어는
지금 쓰는 한글 그대로 씁니다. 지금 한글에 없는 소리, 곧 f·v·th, 스페인어의 떨림소리, 중국어의
성조는 익숙한 글자에 작은 표시 하나를 더해 적습니다.

**▶ 한국어 페이지: <https://dotori-ai.github.io/Phonetic-Script/ko/>**

새 글자는 프로젝트 전용 글꼴로 그려집니다. GitHub 화면에는 이 글꼴이 없으므로, 아래에서는
새 글자를 `[초성+중성+종성]` 구성으로 적었습니다. 실제 글자는 위 페이지에서 보세요.

## 훈민정음은 처음부터 더 많은 소리를 적었습니다

1443년 세종이 만든 훈민정음 28자에는 지금은 쓰지 않는 글자가 넷 있습니다. 15세기 한국어에
있던 소리를 위한 글자들입니다.

| 글자 | 이름 | 소리 |
|---|---|---|
| ㆍ | 아래아 | ㅏ와 ㅗ 사이의 모음. 표준어에서는 사라졌지만 제주어에는 아직 남아 있습니다. |
| ㅿ | 반치음 | /z/에 가까운 울림소리. 16세기 무렵 사라졌습니다. |
| ㆆ | 여린히읗 | 목청을 닫았다 여는 소리(성문 파열음). 주로 한자음을 적는 데 쓰였습니다. |
| ㆁ | 옛이응 | 받침 ㅇ의 /ŋ/ 소리. 소리가 없는 초성 ㅇ과 따로 적었습니다. |

### 이어 쓰기(연서): 기본 글자 + 표시 = 새 소리

훈민정음은 새 소리가 필요할 때 글자를 새로 만들지 않고, 있는 글자에 ㅇ을 이어 붙였습니다.
입술소리 아래에 ㅇ을 쓰면 입술을 가볍게 스치는 소리가 됩니다.

| 글자 | 이름 | 소리 |
|---|---|---|
| ㅸ | 순경음 비읍 | ㅂ 아래에 ㅇ을 이어 쓴 글자. 입술을 가볍게 스치는 /β/ 소리입니다. |
| ㆄ | 순경음 피읖 | /f/에 가까운 소리. 중국 한자음을 적을 때 썼습니다. |
| ㅱ | 순경음 미음 | 입술을 가볍게 하는 m. 역시 한자음 표기에 쓰였습니다. |

### 나란히 쓰기(병서)와 방점

단어 첫머리의 자음 묶음도 한 칸에 나란히 적었습니다: ㅺ(ㅅ+ㄱ), ㅼ(ㅅ+ㄷ), ㅄ(ㅂ+ㅅ).
그리고 글자 왼쪽에 점을 찍어 소리의 높낮이를 표시했습니다.

| 방점 | 이름 | 높낮이 |
|---|---|---|
| 없음 | 평성 | 낮은 소리 |
| 점 하나 | 거성 | 높은 소리 |
| 점 둘 | 상성 | 낮았다가 높아지는 소리 |

성조를 글자에 직접 적은 드문 사례입니다.

## 새 글자의 구조

Phonetic Script(기술 이름 확장 한글, EK)는 이 원리를 그대로 잇습니다. 연서처럼 기본 글자에
표시를 더하고, 병서처럼 받침 자리에 겹자모를 쓰고, 방점처럼 성조를 글자에 적습니다. 다른
점은 표시마다 **자리가 정해져 있다**는 것입니다. 그래서 한 번 보면 무엇이 바뀌었는지 바로
읽힙니다.

| 자리 | 하는 일 | 예 |
|---|---|---|
| 초성 표시 · 위 / 오른쪽 위 | 지금 한글에 없는 자음 | `ㅍ'` = f · `ㅂ~` = v · `ㄱ'` = x · `ㅌㅎ` = th · `ㄹ-` = 떨리는 r · `ㄴ^` = ñ |
| 중성 왼쪽 | 소리의 질 | `·ㅓ` = /ə/ · `·ㅗ` = /ɔ/ |
| 중성 오른쪽 | 길이 | `ㅏː` = 긴 /aː/ |
| 위쪽 | 운율 | 성조(ā á ǎ à처럼 모음 위에), 강세(ˈ ˌ), 높낮이 악센트(H L) |
| 종성 · 오른쪽 절반 | 겹받침 ㄳ처럼 | `ㄴ+ˊ` = /ɲ/ 받침 |
| 소리 없는 `ㅡ°` | 자리만 지키는 ㅡ | 실제로 /ɯ/를 발음하지 않습니다 |

규칙은 두 가지입니다.

1. **기본 자모 하나 + 표시 하나 = 새 글자 하나.** 표시를 두 개 겹치지 않고, 소리에 구별이 두
   가지 필요하면 두 글자로 나눠 씁니다.
2. 모든 글자 칸은 **초성 · 중성 · 종성 · 성조 · 강세 · 악센트**의 여섯 자리로 기록되어, 사람이
   읽는 모양과 컴퓨터가 읽는 정보가 언제나 같습니다.

### 외국어를 적어 보면

‘지금 한글’ 칸은 현재 외래어 표기로 적은 것입니다. 지금 한글로는 서로 다른 소리가 같은 글자가
되지만(페로 / 페로), 새 글자에서는 구별됩니다.

| 단어 | 언어 | 새 글자 구성 | 지금 한글 | IPA | 무엇이 다른가 |
|---|---|---|---|---|---|
| coffee | 영어 | `ˈ[ㅋ+ㅏ][ㅍ'+ㅣ]` | 카피 | kʰˈɑːfi | f → ㅍ' |
| video | 영어 | `ˈ[ㅂ~+ㅣ]디오` | 비디오 | vˈɪdioʊ | v → ㅂ~ |
| think | 영어 | `[ㅌㅎ+ㅣ+ㅇ]크` | 띵크 | θɪŋk | th → ㅌㅎ |
| she / see | 영어 | 쉬 / 시 | 시 / 시 | ʃiː / siː | sh는 모음에 둥근 입술(ㅟ)로 |
| jamón | 스페인어 | `[ㄱ'+ㅏ]몬` | 하몬 | xamon | j(/x/) → ㄱ' |
| pero / perro | 스페인어 | 페로 / `페[ㄹ-+ㅗ]` | 페로 / 페로 | peɾo / pero | ‘하지만’과 ‘개’: 떨림소리 rr → ㄹ- |
| niño | 스페인어 | `니[ㄴ^+ㅗ]` | 니노 | niɲo | ñ → ㄴ^ |

### 성조: 방점의 자리를 다시 쓰다

중국어 ma는 성조에 따라 뜻이 넷으로 갈립니다. 지금 한글로는 모두 ‘마’이지만, 새 글자는 방점처럼
성조를 글자 위 정해진 자리에 적습니다.

| 한자 | 새 글자 구성 | 지금 한글 | 성조 |
|---|---|---|---|
| 妈 mā | `[ㅁ+ㅏˉ]` | 마 | 1성 · 높고 평평하게 |
| 麻 má | `[ㅁ+ㅏˊ]` | 마 | 2성 · 올라가게 |
| 马 mǎ | `[ㅁ+ㅏˇ]` | 마 | 3성 · 내려갔다 올라가게 |
| 骂 mà | `[ㅁ+ㅏˋ]` | 마 | 4성 · 내려가게 |

## 후원하기

Phonetic Script는 언어학자와 원어민 화자, 글꼴 디자이너가 함께 만듭니다. 후원금은 이분들의
작업비와, 화자의 동의를 받은 녹음에 쓰입니다. 후원자는 모든 결과물을 일반 공개보다 먼저 받아
봅니다.

| 후원 | 받는 것 |
|---|---|
| 월 5,000원 · 또는 1회 30,000원 | 모든 결과물 선공개, 분기 보고, 후원자 명단에 이름 |
| 월 20,000원 · 또는 1회 100,000원 | + 언어 초안 검토에 의견 남기기, 월 1회 온라인 모임 |
| 월 50,000원 · 또는 1회 300,000원 | + 언어 하나의 문서에 후원자 표기 |
| 1회 1,000,000원 이상 | + 글이 없는 언어 파일럿 하나에 후원자 표기 (화자 공동체와 협의 후) |

- 목표 금액 없는 상시 후원, 받은 만큼 일합니다
- 모든 지출은 공개 장부에 기록합니다
- 후원금은 프로젝트 작업에만 씁니다: 언어학자, 화자, 글꼴, 서버
- 분기마다 후원자에게 보고합니다

후원 창구는 곧 열립니다. 후원 방법은 [한국어 페이지](https://dotori-ai.github.io/Phonetic-Script/ko/#support)에서
안내합니다. 기관·기업 후원이나 상업 라이선스 문의: licensing@dotori.ai
