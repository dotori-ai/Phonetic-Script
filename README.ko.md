# Phonetic Script

**훈민정음의 뜻을, 세계의 말소리로.**

> 나랏말ᄊᆞ미 듕귁에 달아 문ᄍᆞᆼ와로 서르 ᄉᆞᄆᆞᆺ디 아니ᄒᆞᆯᄊᆡ
>
> 나라의 말이 중국과 달라 문자와 서로 통하지 아니하므로, 어리석은 백성이 말하고자 하는 바가
> 있어도 마침내 제 뜻을 펴지 못하는 사람이 많다. 내가 이를 불쌍히 여겨 새로 스물여덟 글자를
> 만드니, 사람마다 쉽게 익혀 날마다 쓰는 데 편하게 하고자 할 따름이다.
>
> — 세종, 『훈민정음』 어제 서문 (1446). 첫 줄은 언해본 원문, 아래는 현대어 풀이

580년 전 세종은 말은 있으되 그 말을 적을 글자가 없는 백성을 위해 훈민정음을 만들었습니다.
『훈민정음』 해례본의 정인지 서문은 이 글자로 *바람 소리와 학의 울음, 닭 울음과 개 짖는
소리까지도 모두 적을 수 있다*고 했습니다. Phonetic Script는 그 뜻을 오늘의 세계로 넓힙니다.

**▶ 한국어 페이지: <https://dotori-ai.github.io/Phonetic-Script/ko/>**

## 훈민정음AI

**말의 차이는 단어보다 발음에 있습니다.** AI 언어 모델을 학습시키면서, 사람들 사이의 차이가 *어떤
단어를 쓰느냐*보다 *어떻게 발음하느냐*에서 훨씬 크다는 것을 알게 되었습니다. 같은 문장을 똑같은
단어로 말해도 텍사스 사람과 오하이오 사람, 경상도 사람과 전라도 사람은 다르게 들립니다. 철자만 읽는
AI는 이 차이를 놓칩니다. 방언과 억양, 말의 뉘앙스를 알아듣는 AI를 만들려면, AI가 소리를 이해해야
하고 소리를 그대로 적는 글자가 필요합니다.

**지금도 말만 있고 글이 없는 사람들이 있습니다.** 인도와 중국에는 말은 있지만 글이 없는 민족이
여전히 많습니다. 인도에서는 곤디어·빌리어·쿠루흐어처럼 수백만 명이 쓰는 말도 대부분 입으로만
전해지고, 글로 적을 때는 다른 언어의 문자를 빌려 써서 그 말만의 소리를 잃습니다. 중국에서는
광둥어·민난어·우어·하카어를 표준 중국어와 같은 한자로 적기 때문에 소리와 성조가 남지 않고, 투자족과
거라오족의 말처럼 전통 문자가 아예 없는 말도 있습니다. 글이 없으면 기록도, 교육도, 멀리 있는
사람과의 소통도 어렵습니다. 1446년 세종이 마주했던 바로 그 문제입니다.

## 더 큰 목표: 6G 음성 AI

저희는 지금 6G 무선 통신을 위한 음성 AI를 연구하고 있습니다. 6G에서는 기기가 소리를 그대로 실어 나르는 데 그치지 않고, 말의 소리와 뜻을 이해해 주고받게 됩니다. 확장 한글은 이 목표의 한 부분입니다. 모든 언어와 방언의 말소리를 사람과 기계가 함께 읽을 수 있도록 정밀하게 적는 글자입니다.

## 확장 한글의 목적

확장 한글(EK)은 **세상의 다양한 발음을 빠짐없이 적기 위한 한글**입니다.

1. **옛한글을 다시 씁니다.** 훈민정음이 적던 소리를 위한 옛한글 자모는 이미 유니코드에 들어 있습니다:
   한글 자모(U+1100–11FF), 한글 자모 확장-A(U+A960–A97F, 옛 초성), 한글 자모 확장-B(U+D7B0–D7FF,
   옛 중성과 종성), 한글 호환 자모(ㆍ ㅿ ㆆ ㆁ ㅸ 등). 확장 한글은 이 글자들을 그대로 살려 씁니다.
2. **그래도 없는 소리는 표시 하나로 더합니다.** f·v·th, 떨리는 r, 성조처럼 옛한글로도 적을 수 없는
   소리는, 훈민정음의 연서(이어 쓰기)처럼 기본 글자에 표시 하나를 더해 새 글자를 만듭니다.
3. **사람과 AI가 같은 글을 읽습니다.** 모든 글자는 같은 여섯 자리 구조로 기록되어, 사람이 읽는
   글자와 AI가 학습하는 정보가 언제나 같습니다. 글이 없는 말도 이 글자로 적어 기록하고, 가르치고,
   AI가 알아듣게 할 수 있습니다.

새 글자는 프로젝트 전용 글꼴로 그려집니다. GitHub 화면에는 이 글꼴이 없으므로, 아래에서는 새 글자를
`[초성+중성+종성]` 구성으로 적었습니다. 실제 글자는 위 페이지에서 보세요.

## 훈민정음이 적던 소리들

1443년 세종이 만든 훈민정음 28자에는 지금은 쓰지 않는 글자가 넷 있습니다. 15세기 한국어에
있던 소리를 위한 글자들입니다.

| 글자 | 이름 | 소리 |
|---|---|---|
| ㆍ | 아래아 | ㅏ와 ㅗ 사이의 모음. 표준어에서는 사라졌지만 제주어에는 아직 남아 있습니다. |
| ㅿ | 반치음 | /z/에 가까운 울림소리. 16세기 무렵 사라졌습니다. |
| ㆆ | 여린히읗 | 목청을 닫았다 여는 소리(성문 파열음). 주로 한자음을 적는 데 쓰였습니다. |
| ㆁ | 옛이응 | 받침 ㅇ의 /ŋ/ 소리. 소리가 없는 초성 ㅇ과 따로 적었습니다. |

### 이어 쓰기(연서): 기본 글자 + 표시 = 새 소리

훈민정음은 새 소리가 필요할 때 글자를 새로 만들지 않고, 있는 글자에 ㅇ을 이어 붙였습니다.
입술소리 아래에 ㅇ을 쓰면 입술을 가볍게 스치는 소리가 됩니다.

| 글자 | 이름 | 소리 |
|---|---|---|
| ㅸ | 순경음 비읍 | ㅂ 아래에 ㅇ을 이어 쓴 글자. 입술을 가볍게 스치는 /β/ 소리입니다. |
| ㆄ | 순경음 피읖 | /f/에 가까운 소리. 중국 한자음을 적을 때 썼습니다. |
| ㅱ | 순경음 미음 | 입술을 가볍게 하는 m. 역시 한자음 표기에 쓰였습니다. |

### 나란히 쓰기(병서)와 방점

단어 첫머리의 자음 묶음도 한 칸에 나란히 적었습니다: ㅺ(ㅅ+ㄱ), ㅼ(ㅅ+ㄷ), ㅄ(ㅂ+ㅅ).
그리고 글자 왼쪽에 점을 찍어 소리의 높낮이를 표시했습니다.

| 방점 | 이름 | 높낮이 |
|---|---|---|
| 없음 | 평성 | 낮은 소리 |
| 점 하나 | 거성 | 높은 소리 |
| 점 둘 | 상성 | 낮았다가 높아지는 소리 |

성조를 글자에 직접 적은 드문 사례입니다.

## 새 글자의 구조

확장 한글은 이 원리를 그대로 잇습니다. 연서처럼 기본 글자에
표시를 더하고, 병서처럼 받침 자리에 겹자모를 쓰고, 방점처럼 성조를 글자에 적습니다. 다른
점은 표시마다 **자리가 정해져 있다**는 것입니다. 그래서 한 번 보면 무엇이 바뀌었는지 바로
읽힙니다.

| 자리 | 하는 일 | 예 |
|---|---|---|
| 초성 표시 · 위 / 오른쪽 위 | 지금 한글에 없는 자음 | `ㅍ'` = f · `ㅂ~` = v · `ㄱ'` = x · `ㅌㅎ` = th · `ㄹ-` = 떨리는 r · `ㄴ^` = ñ |
| 중성 왼쪽 | 소리의 질 | `·ㅓ` = /ə/ · `·ㅗ` = /ɔ/ |
| 중성 오른쪽 | 길이 | `ㅏː` = 긴 /aː/ |
| 위쪽 | 운율 | 성조(ā á ǎ à처럼 모음 위에), 강세(ˈ ˌ), 높낮이 악센트(H L) |
| 종성 · 오른쪽 절반 | 겹받침 ㄳ처럼 | `ㄴ+ˊ` = /ɲ/ 받침 |
| 소리 없는 `ㅡ°` | 자리만 지키는 ㅡ | 실제로 /ɯ/를 발음하지 않습니다 |

규칙은 두 가지입니다.

1. **기본 자모 하나 + 표시 하나 = 새 글자 하나.** 표시를 두 개 겹치지 않고, 소리에 구별이 두
   가지 필요하면 두 글자로 나눠 씁니다.
2. 모든 글자 칸은 **초성 · 중성 · 종성 · 성조 · 강세 · 악센트**의 여섯 자리로 기록되어, 사람이
   읽는 모양과 컴퓨터가 읽는 정보가 언제나 같습니다.

### 외국어를 적어 보면

‘지금 한글’ 칸은 현재 외래어 표기로 적은 것입니다. 지금 한글로는 서로 다른 소리가 같은 글자가
되지만(페로 / 페로), 새 글자에서는 구별됩니다.

| 단어 | 언어 | 새 글자 구성 | 지금 한글 | IPA | 제안 |
|---|---|---|---|---|---|
| coffee | 영어 | `[ㅋ+ㅓ][ㅍ'+ㅣ]` | 커피 | ˈkʰɔfi | f는 ㅍ'으로 임시 제안 |
| video | 영어 | `ˈ[ㅂ~+ㅣ]디오` | 비디오 | vˈɪdioʊ | v는 ㅂ~으로 임시 제안 |
| think | 영어 | `[ㅌㅎ+ㅣ+ㅇ]크` | 띵크 | θɪŋk | th는 ㅌㅎ으로 임시 제안 |
| she / see | 영어 | 쉬 / 시 | 시 / 시 | ʃiː / siː | sh는 둥근 입술 모음 ㅟ로 임시 제안 |
| jamón | 스페인어 | `[ㄱ'+ㅏ]몬` | 하몬 | xamon | j(/x/)는 ㄱ'으로 임시 제안 |
| pero / perro | 스페인어 | 페로 / `페[ㄹ-+ㅗ]` | 페로 / 페로 | peɾo / pero | 떨리는 rr은 ㄹ-로 임시 제안 (‘하지만’과 ‘개’를 구별) |
| niño | 스페인어 | `니[ㄴ^+ㅗ]` | 니노 | niɲo | ñ는 ㄴ^으로 임시 제안 |

### 성조: 방점의 자리를 다시 쓰다

중국어 ma는 성조에 따라 뜻이 넷으로 갈립니다. 지금 한글로는 모두 ‘마’이지만, 새 글자는 방점처럼
성조를 글자 위 정해진 자리에 적습니다.

| 한자 | 새 글자 구성 | 지금 한글 | 성조 |
|---|---|---|---|
| 妈 mā | `[ㅁ+ㅏˉ]` | 마 | 1성 · 높고 평평하게 |
| 麻 má | `[ㅁ+ㅏˊ]` | 마 | 2성 · 올라가게 |
| 马 mǎ | `[ㅁ+ㅏˇ]` | 마 | 3성 · 내려갔다 올라가게 |
| 骂 mà | `[ㅁ+ㅏˋ]` | 마 | 4성 · 내려가게 |
