How it reaches the model: Export → attach ek_word_lexicon.json to a new issue or pull request in this repository (see CONTRIBUTING.md); maintainers merge it into the project lexicon. The G2P re-reads the lexicon whenever the file changes: ek wins over ipa, which wins over CMUdict / epitran / letter rules. Blocks typed as [ㅍ'+ㅠ] that the registry has not seen are minted when the file is applied (append-only) — rebuild the font afterwards so they have glyphs. Sound-level policy (which consonants get extended jamo, epenthesis, clusters) lives in data/ek_mark_profiles.json.
